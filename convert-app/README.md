# ממיר טיול 🇬🇪 — ₪ ₾ $

אפליקציית ווב חד-דפית (ללא צורך בהתקנה/בילד) לניהול טיול בגאורגיה: המרת מטבעות בין שקל (ILS), דולר (USD) ולארי גאורגי (GEL), יחד עם פנקס הוצאות מלא.

## שימוש

פתחו את `index.html` בדפדפן (או הגישו את התיקייה כאתר סטטי, למשל דרך GitHub Pages). כל הנתונים נשמרים מקומית בדפדפן (`localStorage`) — אין שרת, אין חשבון, אין שיתוף מידע.

להוספה למסך הבית באייפון: פתחו ב-Safari ← שתפו ← "הוסף למסך הבית".

## מסכים

- **💱 ממיר** — המרה חיה בין שלושת המטבעות, עריכת שערים ידנית או עדכון אוטומטי (`open.er-api.com`), והעברת סכום ישירות לפנקס ההוצאות.
- **💰 הוצאות** — הוספה מהירה לפי קטגוריה (אוכל, לינה, תחבורה, אטרקציה, קניות, קפה/בר, מכולת, אחר), סינון לפי הכל/היום/7 ימים, ומחיקת רישומים.
- **📊 סיכום** — מעקב תקציב עם פס התקדמות והתראת חריגה, ממוצע יומי, פילוח הוצאות לפי קטגוריה, ייצוא ל-CSV, גיבוי/שחזור JSON, ומחיקת כלל הנתונים (עם אישור כפול).

## קבצים

- `index.html` — כל האפליקציה (מבנה, עיצוב ולוגיקה)
- `manifest.json` — הגדרות PWA לצורך הוספה למסך הבית
- `sw.js` — Service Worker בסיסי לתמיכה במצב לא מקוון
- `icon.svg` — אייקון האפליקציה

## פרטיות

כל הנתונים נשמרים אך ורק על גבי המכשיר. הפעולה היחידה שדורשת אינטרנט היא עדכון שערי חליפין אוטומטי — ניתן גם להזין שערים ידנית ולהשתמש באפליקציה במלואה במצב לא מקוון.
